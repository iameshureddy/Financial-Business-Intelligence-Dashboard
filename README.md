# Financial Business Intelligence Dashboard

An interactive financial analytics and business intelligence dashboard designed to monitor financial performance, analyze costs, evaluate cash flow, and support data-driven business decisions.

**Live Demo:** https://used-grape.surge.sh/

## Overview

The Financial Business Intelligence Dashboard provides a consolidated view of key financial indicators through interactive visualizations and KPI summaries. It helps users understand revenue and expense trends, evaluate profitability, monitor cash availability, and assess financial sustainability.

The dashboard brings together financial reporting and business analysis across seven modules: Overview, Capital Expenditure (CapEx), Operating Expenditure (OpEx), Cash Flow, Burn Rate, Runway, Break-Even Point (BEP), and Working Capital.

## Key Features

### 1. Financial Overview
- Displays key financial indicators in a centralized dashboard.
- Tracks cash flow, burn rate, runway, CapEx, OpEx, break-even status, and working capital.
- Presents revenue and expense trends.
- Highlights profitability gaps and important financial patterns.

### 2. Capital Expenditure (CapEx) Analysis
- Visualizes capital expenditure allocation.
- Compares capital investments across categories.
- Presents expenditure distribution through charts and comparative visualizations.
- Supports analysis of investment allocation and spending patterns.

### 3. Operating Expenditure (OpEx) Analysis
- Examines operating expenses and cost distribution.
- Highlights major expense categories.
- Visualizes the relationship between operating costs and profitability.
- Supports expense monitoring and cost-structure analysis.

### 4. Cash Flow Analysis
- Tracks cash flow trends over time.
- Examines cash inflows, outflows, and net cash flow.
- Helps identify changes in cash availability.
- Supports financial liquidity monitoring.

### 5. Burn Rate Analysis
- Monitors the rate at which cash is consumed.
- Compares revenue and expenses to evaluate financial pressure.
- Highlights trends that may affect cash sustainability.
- Supports financial planning and spending control.

### 6. Runway Analysis
- Estimates how long available cash can support ongoing operations.
- Visualizes projected cash depletion.
- Helps evaluate financial sustainability under the displayed assumptions.
- Supports planning for future funding and expenditure.

### 7. Break-Even Point (BEP) Analysis
- Compares revenue with costs.
- Presents break-even analysis using the dashboard's displayed financial assumptions.
- Helps identify the sales volume or revenue level required to cover costs.
- Supports profitability planning.

### 8. Working Capital Analysis
- Displays working capital indicators.
- Visualizes capital movement and financial risk levels.
- Supports assessment of short-term financial flexibility.
- Helps users understand the relationship between available operating capital and business requirements.

## Data Analytics and Business Intelligence

The project focuses on financial data interpretation and business performance monitoring through:

- **Financial KPI Analysis:** Monitoring key financial metrics.
- **Trend Analysis:** Comparing revenue, expenses, and cash flow patterns.

## Getting Started

### Prerequisites
- Node.js
- npm
- Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/iameshureddy/Financial-Business-Intelligence-Dashboard.git
```

2. Navigate to the project directory:

```bash
cd Financial-Business-Intelligence-Dashboard
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local development URL shown in the terminal, typically:

```text
http://localhost:3000
```
